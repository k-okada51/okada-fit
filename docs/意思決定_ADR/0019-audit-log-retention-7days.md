## 背景・課題（Context）
> 📝 ここに何を・なぜ決める必要があるかを記載。関連する要件ID（FEAT/NFR/DM/IF/ST/ERR）を明記する。{決定が必要な理由／制約／前提}

- **対象要件**: NFR-SEC-AUDIT-01（外部送信の記録）・NFR-SEC-AUDIT-02（認証の成否）。
- 2026-08-08 に Supabase 無料枠のログ保持期間を公式の料金ページで確認した。**7日**である。
- 本PJの監査ログは Supabase のマネージドログにのみ出す。専用テーブルは持たない（`05_ログ設計.md §1-1`）。
- **したがって8日目以降の証跡は残らない。** 復元手段も無い。

| 期間 | 追えるか |
|---|---|
| 発生から7日以内 | 追える |
| 8日目以降 | **追えない。** 復元手段が無い |

- 「先月このAIリクエストを送ったか」という問いには答えられない。
- 一般に監査ログは喪失不可とされる。**本PJはその原則を満たさない。** 明示的な判断が要る。

|---|---|---|---|
| **A（採用）** | **7日のまま許容する** | 追加のコスト・実装・テーブルが要らない | 8日目以降の証跡が無い。長期の調査ができない |
| B | Log Drain を契約する（有料プラン） | 長期保持できる。実装が不要 | 月額費用が発生する。ADR-0016（コスト最小）と不整合 |
| C | 外部送信の要約をDBの監査テーブルに残す | 保持期間を自分で決められる。無料枠のまま | **11番目のテーブルが増える**。`01_DB物理設計.md` の改訂・RLS・マイグレーションの保守が増える。`05_ログ設計.md §1-1` の判断を覆す |

## 決定（Decision）
> 📝 ここに採用案と、具体値・方式を実装が迷わない粒度で記載。{採用案／確定した具体値・方式}

案 **A** を採用する。**保持は7日とし、それを超える監査ログの喪失を許容する。**

| 項目 | 値 |
|---|---|
| 保持期間 | **7日**（Supabase 無料枠の既定） |
| 保存先 | Supabase のマネージドログのみ（Edge Function ログ／Auth ログ／Postgres ログ） |
| 監査テーブル | **作らない**（`05_ログ設計.md §1-1` の判断を維持） |
| Log Drain | **契約しない** |
| 8日目以降 | 追えないことを**許容する** |

- `05_ログ設計.md §4` の `[仮]`（監査ログの喪失を許容する）を**確定に変える**。
- 監査ログの位置づけを改める。**証跡ではなく、直近の障害調査に使う道具**とする。

## 根拠（Rationale）
> 📝 ここになぜその案かを記載。トレードオフ・却下理由を明示する。{選定理由／却下した案の理由}

- **監査の相手がいない。** 利用者は岡田さん本人1人で、第三者に証明する場面が無い。
- **NFR-SEC-AUDIT が求める水準が低い。** 要件側に「個人利用のため厳格な監査は必須ではない。最低限、外部送信・エラーの記録に留める」とある。
- **実際の用途は障害調査である。** 「AI解析が失敗した」「ログインできない」の原因を追うのが目的で、7日あれば足りる。気づいてから1週間放置することは考えにくい。
- **案Cのコストが見合わない。** テーブル1つの追加は、DB設計・RLS・マイグレーション・容量の保守を恒久的に増やす（NFR-MAINT-01 に逆行）。得られるのは「1人しか使わないアプリの長期証跡」である。

**却下理由**

| 案 | 却下理由 |
|---|---|
| B | 月額費用が発生する。得るものが長期の証跡だけで見合わない |
| C | 11番目のテーブルの保守が恒久的に乗る。個人開発の負担に見合わない |

## 影響（Consequences）
> 📝 ここに決定がもたらす影響を記載。{反映先ドキュメントの該当箇所／関連テスト観点／前提が崩れた場合の再検討条件}

- **NFR-SEC-AUDIT-01 は「7日までの証跡」としてしか機能しない。** 要件の文言と実態に差がある。
  - ⚠️ 要確認（人間判断）: **NFR-SEC-AUDIT-01 の文言を実態に合わせるか（🟡 中）。**
  - 「後から追える」ではなく「直近7日は追える」が実態である。
  - 段1（`01_要件定義/04_非機能要件.md`）の改訂を伴うため本ADRでは決めない。**要件ブランチへの申し送りとする。**
- **業務データとは扱いが違う。** DBのバックアップは日次エクスポートで担保する（ADR-0017）。ログはその対象外である。
- 監査ログの喪失は**設計上の想定**になる。障害調査で「ログが無い」ことを異常として扱わない。
