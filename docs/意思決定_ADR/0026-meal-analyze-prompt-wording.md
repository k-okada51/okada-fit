## 背景・課題（Context）
> 📝 ここに何を・なぜ決める必要があるかを記載。関連する要件ID（FEAT/NFR/DM/IF/ST/ERR）を明記する。{決定が必要な理由／制約／前提}

- **対象要件**: FEAT-08（食事撮影タンパク質計算）。連携は EXT-01。
- FEAT-08 §3.2 は `MEAL_ANALYZE_PROMPT` を参照しているが、**本文が設計書のどこにも無い。**
- §10 #9 が「プロンプト文言が未確定（🟡 中）」として残していた。**W-11 の実装で本文が必要になった。**
- 実体は PoC（`poc/food-vision/src/config.mjs` の `PROMPT`）にあり、ADR-0001 の実測はこの文言で行われた。

### PoC の文言は外食を断定している

```text
この写真は日本のコンビニまたはファストフード・外食チェーンの商品です。
写真に写っている食品1個（1食分）の栄養成分を、見た目・種類・量から推定してください。
```

- **「〜商品です」と断定している。** PoC のデータセットが外食23チェーンだけだったためである。
- **本番では自炊も撮る。** 断定を残すと、家庭料理を既製品として推定させることになる。
- 家庭料理は量も具材も店の商品と揃わない。**外れる方向に誘導する文である。**

## 選択肢（Options / Alternatives）
> 📝 ここに検討した案を記載（採用案・却下案の両方）。{案／概要／長所／短所}

| 案 | 概要 | 長所 | 短所 |
|---|---|---|---|
| **A（採用）** | **断定を外し、外食と家庭料理の両方を想定させる文にする** | 実利用の分布に合う。変更は1文字列 | **ADR-0001 の実測 MAPE がこの文言のものでなくなる** |
| B | PoC の文言のまま実装する | 実測値の前提が保たれる | **最初の自炊で外すと分かっていて出す。**理由が無い |
| C | 文言を変え、PoC データセット220件で再ベンチしてから実装する | 精度が数字で裏付く | 実費が出る。W-11 が止まる |

## 決定（Decision）
> 📝 ここに採用案と、具体値・方式を実装が迷わない粒度で記載。{採用案／確定した具体値・方式}

案 **A** を採用する。**断定を外す。**

```text
この写真は日本の食事です。
コンビニ・ファストフード・外食チェーンの商品の場合もあれば、家庭料理の場合もあります。
写真に写っている食事1食分の栄養成分を、見た目・種類・量から推定してください。
```

| 項目 | 内容 |
|---|---|
| 置き場所 | `supabase/functions/analyze-meal/prompt.ts` の `MEAL_ANALYZE_PROMPT` |
| 変えたこと | 「〜商品です」（断定）→「〜の場合もあれば、家庭料理の場合もあります」 |
| 変えていないこと | 「1食分」「見た目・種類・量から推定」という指示の骨格 |
| 変えていないこと | `response_schema` の各 `description`（PoC 実測時のまま） |

**`response_schema` の description は動かさない。** あれも Gemini への指示であり、
同時に2か所変えると、精度が動いたときにどちらのせいか切り分けられない。

## 根拠（Rationale）
> 📝 ここになぜその案かを記載。トレードオフ・却下理由を明示する。{選定理由／却下した案の理由}

- **B は出す前から外れると分かっている。** 岡田さんが自炊を撮るのは想定内であり、そこで外す実装を出す理由が無い。
- **C は順序が逆である。** 再ベンチは実装が動いてからでも回せる。W-11 を止める理由にならない。
- **A の代償は「数字の裏付けが無くなること」だけ**で、動かなくなるわけではない。実測は後から足せる。

**却下理由**

| 案 | 却下理由 |
|---|---|
| B | 最初の実利用で外すことが分かっている |
| C | 実装を止める。再ベンチは後追いできる |

## 影響（Consequences）
> 📝 ここに決定がもたらす影響を記載。{反映先ドキュメントの該当箇所／関連テスト観点／前提が崩れた場合の再検討条件}

- ⚠️ **ADR-0001 の実測 MAPE（外食 総合14.7%・家庭料理18.8%・脂質32.7%）は旧文言のものである。**
  - **本ADRの文言では測っていない。** 精度の数値を引用するときは必ずこの断りを付けること。
  - ADR-0025（モデルを `gemini-3.7-flash` へ）と合わせ、**実測の前提は2つ変わっている**（モデルと文言）。
- **再ベンチの手段は残っている。** PoC の `dataset/ground_truth.json`（220件・23チェーン）と実行ハーネスは
  `poc/food-vision/` にそのまま在る。画像は gitignore だが手元にある。
  - 概算費用は 220件 × $0.002 ≒ **$0.5**。ハーネスは Vercel AI Gateway 経由のため、Google 直へ向け直す改修が要る。
- 反映先:
  - `02_設計/50_詳細設計/08_機能別詳細設計/FEAT-08_食事撮影タンパク質計算.md §3.2`（本文の所在）・`§10 #9`（未決の解消）
- 関連テスト観点: プロンプトは純粋な文字列定数のため単体テストの対象にしない。
  実地の確認は W-11 の疎通（自炊1枚・外食1枚）で行う。
- 前提が崩れた場合の再検討条件:
  - 実利用で家庭料理の推定が明らかに外れる → 文言を見直すか、再ベンチ（案C）へ進む
  - 逆に外食の精度が落ちた → 断定を外したことが原因の可能性がある。旧文言と比較する
