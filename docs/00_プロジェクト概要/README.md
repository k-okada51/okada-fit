# 00_プロジェクト概要

> 人間が**最初に読む1枚**。この案件が「何を・なぜ・誰のために・どう解決するか」を俯瞰する（①）。

## この層に置くもの
- `01_プロジェクト概要_人間向け.md` … 目的/ビジネス価値/システム全体像/登場人物の俯瞰（1枚）
- `02_体制・役割.md` … 発注元・当社の体制、判定者
- `03_契約・スコープ.md` … 請負固有（顧客・契約・In/Out スコープ）
- `04_適用マトリクス.md` … 本PJで作る文書の宣言（既定の必須/任意 → 適用/該当なし・理由）。完全性統制の「入口」
- `05_設計着手チェックリスト.md` … 実装（TDD）に入れるかの可否ゲート（RED源泉/内部ADR/外部IF/データ基盤/画面モック）。台帳とはID参照で重複しない

## この層に置かないもの（他層の正本）
| 成果物 | 正本 |
|---|---|
| 詳細な機能要件 | `01_要件定義/02_機能要件/` |
| 業務フロー | `01_要件定義/01_全体像/02_課題・解決・業務フロー.md` |
| システム構成の詳細 | `02_設計/10_システム基本設計/` |
