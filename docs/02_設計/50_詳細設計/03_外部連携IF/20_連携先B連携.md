# {連携先B} 連携 — EXT-__ / EXT-__

> もう一方の連携先（例: クライアント側連携・書き戻し）のIF仕様。方式（同期直呼び／Webhook等）と封じ込め・認証の前提を明記。契約スキーマ（JSON例）は改変せず既存キーに従う。共通非機能は [`README.md`](README.md#共通-連携の直列化冪等再送)。

## EXT-__ {リクエスト起動}
> 📝 ここにリクエスト起動のIF（同期受付など）を記載。封じ込め・認証の前提（IP許可／レート／スコープ／キー失効・ローテ）を添える。

```jsonc
// Request  {METHOD} /{path}
{ "{field1}": "string", "{field2}": "uuid", "timestamp": "ISO8601", "signature": "hex" }
// Response {status_code}
{ "{ref}": "string", "status": "{ACCEPTED等}", "{idempotency_key}": "string" }
```
- {封じ込め・認証の前提（IP許可／レート／スコープ／キー失効・ローテ）。関連DEC-__}
