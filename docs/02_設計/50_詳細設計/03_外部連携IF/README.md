# 外部連携IF仕様（実装レベル） — 索引＋共通

> **目的**: 外部システム・外部SaaSとの連携を、**実装が迷わない粒度**（認証・エンドポイント・手順・データ構造・エラー）でIF単位に固定する。**連携先が複数ある場合は連携先ごとに1ファイル**へ分割し（`10_{連携先A}連携.md` / `20_{連携先B}連携.md`…）、本READMEを索引＋共通とする。連携先が1つなら本README1枚でよい。
> **書き方**:（記入例は example-suido-fax の対応フォルダ参照）実データは書かず、`{ }` を自プロジェクトの語に置き換える。**契約雛形・IF一覧の正本は `システム基本設計`／`30_データ・IF設計/02_API設計.md`**。**外部ワイヤ（既存API契約）は改変しない**方針を明記し、`EXT-*` でリンクする。
